# 开拓者：殖民地 · Godot 版

> 2D 俯视角 **外星殖民开荒**：塔防 + 开放世界探索 + 城镇经营。
> 这是 **Godot 4.4（GDScript）** 版本，和 [HTML/Canvas 原版](https://github.com/gagagacc/frontier-colony) 是两个独立项目。

## 直接玩（不用装 Godot）

到 **[Releases](../../releases)** 下载 `开拓者-殖民地-Godot版.zip`，解压后双击 `开拓者-殖民地.exe` 即可。
绿色版，不写注册表、不需要安装。

## 用 Godot 打开源码

**本仓库的根目录就是 Godot 工程**（`project.godot` 在根上）：

```
git clone https://github.com/gagagacc/frontier-colony-godot.git
```

然后用 **Godot 4.4.x** 打开这个目录，按 F5 运行。

> 第一次打开会导入资源（几十秒）。运行时如果提示缺导出模板，
> 只在「要导出 exe」时才需要，玩和改代码都不需要。

## 这个版本有什么

| 系统 | 说明 |
|---|---|
| 世界生成 | 5 层噪声 → 群系 / 虫巢 / 地标 / 悬崖签名，与 JS 版**逐位一致** |
| 寻路 | 流场寻路（后台线程计算，主线程不等它） |
| 战斗 | 射击几何（多弹道 / 穿透 / 散布）、11 种防御塔、怪物与 Boss |
| 虫巢副本 | 分区域挖掘 + Boss 房 + 入口大厅；**在虫巢死亡会撤出并回基地复活** |
| 成长 | 科技树（含生物学家与驾驶员各自的专属分支）、装备与词缀、实验科技 |
| 经营 | 城镇人口 / 岗位 / 生产 / 制造、载具 |
| 界面 | 开场流程（标题 → 模式 → 角色 → 星球 → 生成）、16 个面板、中文字体 |

## 验证

这个移植不是「看起来能跑」，而是**和 JS 版逐位对比**：

```bash
node tools/godot-verify.mjs      # 黄金对比（5964 条断言）+ 120 秒长时模拟
```

`tools/godot-golden.mjs` 用 JS 实现算出期望值 → `tests/golden.json`，
再由 `tests/run_tests.gd` 在 GDScript 里重算比对 —— 覆盖世界生成的 8 个阶段哈希、
整张流场哈希、每只怪的逐字段数值、塔与科技的矩阵、副本四个等级的地图哈希、
波次组成、Boss 冲撞 60 帧、状态效果 180 帧、存档往返……

> ⚠️ 黄金值由 **HTML 原版**那套 JS 数据生成，所以本仓库里的 `data/*.json`
> 是**生成产物**（已提交，保证 clone 下来就能跑）。要重新生成需要原版仓库的 `src/`。

## 为什么仓库里没有 exe

构建产物、引擎二进制、素材源包都在 `.gitignore` 里 —— 都能从源码重建，
而 GitHub 单文件上限 100 MB，塞进去既推不动也没意义。
要 exe 请去 [Releases](../../releases)；要自己导出：

```bash
# 需要 Godot 4.4.x 与导出模板
node tools/godot-export.mjs
```
